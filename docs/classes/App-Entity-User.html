implements UserInterface, PasswordAuthenticatedUserInterface uses TimestampableTrait

User.php : 21

Represents a registered platform user.

Users can hold ROLE_USER (client) or ROLE_ADMIN. A new account is unverified until the user clicks the activation link sent by email. Only verified users can purchase content.
